IBI MAE: Mean absolute error (MAE) between the decoded and reference inter-beat interval (IBI) curves within the displayed listening window, measured in seconds (lower is better).

What you are hearing: Each case includes its complete 30- or 40-second performance. Every option overlays its events on exactly the same recording. SMC has no downbeat annotations, so both SMC examples use one uniform beat click; GTZAN retains distinct beat and downbeat clicks. Selected for illustration, not aggregate evaluation. All decoders use a 30–300 BPM range; all other settings use their defaults.
