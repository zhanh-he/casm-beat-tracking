What you are hearing

Beat clicks are synthesized from the event arrays shown above. A higher click marks a predicted downbeat when available. SMC provides beat references but no reference downbeat labels in this protocol.

Each case includes its complete 30- or 40-second performance. Every option overlays its events on exactly the same recording. SMC has no downbeat annotations, so both SMC examples use one uniform beat click; GTZAN retains distinct beat and downbeat clicks.

PLPDP combines predominant local pulse evidence with dynamic programming to follow local tempo changes. CASM instead decodes activation-derived beat candidates with a local duration prior and can retain the direct path when structuring is risky. Neither requires updating the Beat This front-end here. The selected tracks illustrate different outcomes; compare F1 with CMLt/AMLt rather than treating any one example as a benchmark.
