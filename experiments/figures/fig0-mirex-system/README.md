# MIREX system diagram

The root README presents the paper figure and the selected horizontal system
diagram. This directory holds the system diagram and its editable source.

| Slot | Final content |
|---|---|
| [`../fig1-correct.png`](../fig1-correct.png) | Corrected paper Figure 1 showing CASM's behaviour. |
| [`mirex-system.png`](mirex-system.png) | Selected B layout with the six post-processor options. |

Edit [`mirex-system.pptx`](mirex-system.pptx) to revise the system diagram, then export it
as `mirex-system.png`. The diagram is editable. PLPDP and CRF use gray boxes;
all other post-processor boxes are white. The explanatory text about the
submission protocols stays outside the figure. The root README displays
each figure at up to 860 px.

The MIREX abstract badge links to `mirex2026/ABSTRACT.md`. Add the final abstract
there, or update the badge to point to its final PDF when available.
